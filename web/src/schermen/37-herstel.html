Gegevens terugzetten

Welkom terug

Heb je Tools opnieuw geïnstalleerd? Dan zet de app alles terug uit je laatste versleutelde backup: notities, instellingen, automatiseringen, opnames, routes, de kluis, je VPN en koppelingen. Kies de map waar je backups staan (bijvoorbeeld je USB-stick of OneDrive).

Let op: wat er nu op deze telefoon in Tools staat, wordt vervangen door wat in de backup staat.

Overslaan kan altijd: je kunt dit later nog doen bij Alles back-uppen → Alles terugzetten na herinstallatie. Taalmodellen en spraakmodellen zitten niet in de backup; die downloadt de app daarna opnieuw (alleen via wifi als je dat zo hebt ingesteld).

Welke backup?

Bezig met controleren…

De hele backup wordt gelezen en gecontroleerd. Er verandert nog niets.

Klaar om terug te zetten

Let op: wat er nu op deze telefoon in Tools staat, wordt vervangen door wat in deze backup staat. Ook het wachtwoord van je backups wordt dat van deze backup, en je backup-map wordt de map die je net koos.

Daarna start de app opnieuw. Toestemmingen van Android (zoals sms, contacten en meldingentoegang) kunnen niet mee terug: die vraagt de app je daarna opnieuw.

Oudere backup

Deze backup is gemaakt vóór "Alle appgegevens". Je kunt er wel losse onderdelen uit terugzetten (notities, contacten, instellingen …); die worden toegevoegd aan wat er staat.

✓ Je gegevens staan terug

Android zet een paar dingen niet terug. Sta ze hieronder opnieuw toe; wat al in orde is, staat er met een vinkje bij.
