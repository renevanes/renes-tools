Google

Waarvoor mag Tools Google gebruiken?

Eenmalig: Google geeft alleen toegang via een eigen (gratis) Google-project.

  1. Open de Google Cloud Console en maak een project (naam bijv. "Tools").
  2. Zet de Gmail API en/of de Google Drive API aan (Inschakelen).
  3. Ga naar Google Auth Platform, tik op Aan de slag, vul een app-naam en je mailadres in en kies Extern.
  4. Bij Doelgroep: tik op App publiceren (In productie). Anders vervalt de koppeling na 7 dagen.
  5. Bij Clients: Client maken, type Desktop-app. Kopieer de Client ID en het Client secret hieronder.

Google zegt daarna mogelijk "Google heeft deze app niet geverifieerd": het is je eigen app, tik op Doorgaan en vink de gevraagde rechten aan.
