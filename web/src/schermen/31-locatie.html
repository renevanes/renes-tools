Locatie kiezen

Eenmalig instellen

Android laat alleen een app die je zelf aanwijst de locatie doorgeven. Dat gaat via de ontwikkelaarsopties:

  1. Zet de ontwikkelaarsopties aan: Instellingen → Over het apparaat → Versie → tik 7 keer op Buildnummer.
  2. Open de ontwikkelaarsopties (Instellingen → Aanvullende instellingen → Ontwikkelaarsopties).
  3. Zoek de instelling om een app voor de locatie te kiezen (bij Foutopsporing; in het Engels Select mock location app) en kies Rene's Tools.
  4. Kom terug naar deze app.
